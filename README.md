# Shopping STC

A free, open-source shopping app built for small local sellers who can't afford expensive e-commerce platforms.

## Why I'm building this

Most online store tools are either costly or way too complicated for a small shopkeeper. I wanted to build something simple that anyone can set up, customize, and actually use, without paying monthly fees.

## Status

Early stage. I'm building this in the open and the codebase is still taking shape. Things will change often.

## Planned features

- Product catalog with categories and search
- Cart and checkout
- Online payments
- Order tracking for customers
- Seller dashboard to manage products and orders
- Support for regional languages

## Tech stack

- Mobile app: React Native (Expo)
- Backend: Node.js with Express
- Database: MongoDB
